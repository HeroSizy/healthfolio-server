AI assistants (MCP)

Turned off: no assistant can connect. Tokens are kept and work again when you turn it back on.

Let Claude or another MCP client read your health data (read-only). Create a token for it; you can revoke it above like any device.

Copy it now, it won't be shown again.

On this computer, desktop apps can also run it over stdio without a token:

{"mcpServers": {"healthsync": {"command": "healthsync-server", "args": ["mcp"]}}}

Once connected, the assistant offers prompts (weekly review, checkup review, sleep analysis, compare two periods) and resources (database schema, latest checkup, last 7 days).

The skill tells the assistant how to query your data. Install it in Claude Code: SKILL.md
